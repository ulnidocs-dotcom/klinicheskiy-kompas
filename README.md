# Клинический компас — демо-прототип

Статический прототип системы поддержки решений для врачей, ведущих пациентов с тревогой и депрессией на терапии препаратом Авиандр. Три интерфейса: врач (desktop/планшет), пациент (мобильный, формат Telegram Mini App) и клинический психолог (desktop, первичный приём). Без сборки и бэкенда: HTML, CSS, ванильный JS.

## Запуск

```
npm run serve     # http://localhost:5180
npm test          # тесты ядра и хелперов
```

Точки входа: `/` (выбор роли), `/doctor/index.html` (врач), `/patient/index.html?p=p_anna` (пациент), `/psych/index.html` (психолог).
Все роли работают на одном `localStorage` и синхронизируются между вкладками без перезагрузки.

## Структура

| Путь | Назначение |
|---|---|
| `assets/` | ядро: `store.js` (состояние, алерты, аудит), `rules.js`, `scales.js`, `battery.js` (DASS-21, TIPI, ЦТО, маршрут первичного приёма), `therapy.js`, `adherence.js`, `parser.js`; UI: `ui.js`, `doctor.js`, `patient.js`, `psych.js`, стили |
| `data/` | контент: `scales.js`, `intake.js` (анкета, порядок батареи), `cto.js`, `drugs/`, `rules/core.js`, `scenarios.js`, `materials.js` |
| `doctor/` | 10 экранов врача: очередь, карточка, оценка, терапия, маршрутизация, алерты, импорт, сообщения, материалы, профиль |
| `patient/` | экраны пациента, в т. ч. `intake.html` — первичная беседа с психологом |
| `psych/` | кабинет психолога: очередь первичных приёмов, сводка и маршрут, материалы, профиль |
| `tests/` | `node --test` |
| `docs/superpowers/` | спеки и планы |

## Демо-сценарии

1. Анна — новый пациент: назначение Авиандра врачом, приём, опросники.
2. Сергей — взаимодействия с принимаемыми препаратами.
3. Галина — противопоказание (СКФ), назначение вне инструкции с обоснованием.
4. Дмитрий — критический: суицидальные мысли по PHQ-9, C-SSRS, направление к психиатру.
5. Ольга — стабильная положительная динамика, сигналов нет.
6. Илья — первичный приём психолога: батарея заполнена (DASS-21 Д 18, Т 12, С 24 → психотерапия желательно), психолог подтверждает маршрут и передаёт врачу. У Анны приём назначен, но не начат — можно пройти батарею как пациент.

Сброс данных: «Профиль → Сбросить демо-данные» у врача.

## MAX и перенос данных на сайт

Пациентская часть открывается в MAX (мост `st.max.ru/js/max-web-app.js`), Telegram и обычном браузере — различия в `assets/host.js`.
Отметки уходят через очередь `assets/sync.js`; без связи они ждут на устройстве, SOS без связи сообщает «не отправлено».
В профиле пациента — «Открыть дневник на сайте» (одноразовый код на 10 минут) и «Скачать мои данные» (пакет `kompas-bundle v1`, `assets/bundle.js`).
Контракт сервера — `docs/api/`, эталон проверки подписи MAX — `tools/max-initdata.js`, сообщения бота — `data/bot-messages.js`.
Чтобы открыть демо внутри MAX, разместите его по HTTPS и подключите мини-приложение в кабинете организации на платформе MAX.

## Где расширять

- **Шкалы**: `data/scales.js` (пункты, варианты, диапазоны, источник, лицензия).
- **Препараты**: `data/drugs/` (показания, противопоказания, взаимодействия) и `data/drugs/classes.js`.
- **Правила алертов и маршрутизации**: `data/rules/core.js` — декларативно (`when`, `text`, `level`, `routing`, `source`); ядро менять не нужно. Для подсказок врачу-не-психиатру добавьте запись в `HINTS` в `assets/doctor.js`.

## Принципы

Система ничего не назначает: все клинические действия идут через `KK.store.confirm` и пишутся в аудит. Прерывает работу только критический сигнал. Каждый вывод показывает правило и источник.

## Источники

Клинические рекомендации Минздрава России (тревожное расстройство, депрессия), инструкция по применению препарата (ГРЛС), PHQ-9, GAD-7, C-SSRS; для первичного приёма психолога — DASS-21 (русская версия А.А. Золотаревой), TIPI-RU (Сергеева и соавт., 2016), ЦТО (Бажин, Эткинд). STAI не используется (лицензия Mind Garden). Полный перечень с условиями использования — на экранах «Материалы» врача и психолога; батарея и правила маршрута — раздел 13 спеки.

## Ограничения демо

- Данные в `localStorage` браузера: нет бэкенда, аккаунтов и реальной доставки уведомлений.
- Разбор истории болезни — правила и словари, не медицинская NLP-модель.
- Клинический контент (правила, пороги, тексты) требует ревью профильными специалистами до любого реального использования. Правила маршрута психолога — правила команды до экспертной проверки; формулировки C-SSRS для самоотчёта сверить с официальной русской версией.
- Психолог в прототипе даёт предварительную оценку и направление на консультацию, не диагноз (Закон РФ № 3185-1).
- Не медицинское изделие.
